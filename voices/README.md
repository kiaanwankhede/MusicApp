# Singing voice

`sa.mp3 re.mp3 ga.mp3 ma.mp3 pa.mp3` are the sung syllables the app plays (Sa = C4, Re = D4, Ga = E4, Ma = F4, Pa = G4).

They were generated with the open **Kokoro-82M** neural text-to-speech model (Apache-2.0, Hindi female voice `hf_alpha`, Hindi pronunciation सा रे ग म प), then tuned to the exact note pitch, lengthened and given a light vibrato with the WORLD vocoder so they sound sung.

To use a real singer instead, replace these files (same names; .mp3/.m4a/.wav/.ogg/.webm all work) and push — the APK rebuilds automatically. Parents can also record their own voice per note inside the app (Grown-ups area), which overrides these on that device.
